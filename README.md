## ROOM EXPLORER — ТЕСТОВОЕ ЗАДАНИЕ ОТ YADRO | СТАЖИРОВКА ИМПУЛЬС 2026
**Система для исследования комнат и сбора ресурсов** — управление перемещением между комнатами, сбор ресурсов с учётом стоимости и целевого ресурса, оптимизация маршрута при ограниченном количестве еды.

---

## 📖 ОПИСАНИЕ ПРОЕКТА
Система моделирует исследование подземелья с комнатами и ресурсами:

- навигация по комнатам с учётом двусторонних связей;
- сбор ресурсов четырёх типов (железо, золото, самоцветы, опыт);
- учёт стоимости ресурсов (целевой ресурс имеет удвоенную ценность);
- ограничение на количество еды;
- автоматический поиск оптимального пути к непосещённым комнатам;
- фаза возврата на стартовую позицию.

## 🚀 БЫСТРЫЙ СТАРТ

#### 1️. Клонирование репозитория:
```sh
git clone --recurse-submodules https://github.com/safarov-nm/yadro-room-explorer.git
cd yadro-room-explorer
```
#### 2. Сборка проекта:
```sh
# СОЗДАНИЕ ПАПКИ ДЛЯ СБОРКИ
mkdir build
cd build

# КОНФИГУРАЦИЯ СБОРКИ
cmake ..

# КОМПИЛЯЦИЯ
cmake --build . --config Release
```

#### 3. Запуск программы:
```sh
# ОСНОВНАЯ ПРОГРАММА
cd .\room_explorer.exe ..\..\example\in_1.txt
```
